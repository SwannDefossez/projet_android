Fonctionnement

Les 3 blocs de l'application

Ecran 1

Carte

  • affiche les points d'interet
  • propose un lieu a visiter
  • calcule un itineraire pieton
  • met a jour la progression
Ecran 2

Camera

  • capture une photo du lieu
  • compare avec une image de reference
  • calcule des bons matchs ORB
  • valide ou refuse le checkpoint
Ecran 3

Fiche guide

  • nom et adresse du lieu
  • description textuelle
  • lecture / pause de l'audio
  • retour a la carte
Parcours utilisateur

Enchainement principal

Ce que fait l'utilisateur

  • choisit un lieu sur la carte
  • se deplace jusqu'au point selectionne
  • ouvre la camera a proximite
  • prend une photo pour verifier sa presence
  • ouvre la fiche guide si la photo est reconnue

Ce que fait l'application

  • charge les POI depuis les assets
  • recupere la position utilisateur
  • demande un itineraire via OSRM
  • lance l'analyse OpenCV sur la photo
  • transmet les donnees entre ecrans avec des intents

Code choisi

Suggestion du prochain point d'interet

private fun computeSuggestedPoi(
    pois: List<Poi>,
    visitedPoiIds: Set<String>,
    userLocation: LatLng?
): Poi? {
    val candidates = pois.filterNot { it.id in visitedPoiIds }
    if (candidates.isEmpty()) return null
    if (userLocation == null) return candidates.first()

    return candidates.minByOrNull { poi ->
        haversineDistanceMeters(
            fromLat = userLocation.latitude,
            fromLon = userLocation.longitude,
            toLat = poi.latitude,
            toLon = poi.longitude
        )
    }
}

Pourquoi ce code

  • il montre une vraie decision metier
  • il est court et lisible a l'ecran
  • il introduit la notion de distance geographique

Ce que tu peux expliquer

  • on retire d'abord les lieux deja visites
  • s'il n'y a plus de candidat, on retourne null
  • si la position est inconnue, on prend le premier POI
  • sinon on garde le lieu le plus proche
Limite facile a commenter : la recommandation utilise la distance a vol d'oiseau, pas le temps reel de trajet.
